1. Problem Statement
You are given an array coins of different denominations and an integer amount representing a total sum of money. Return the fewest number of coins needed to make up that amount. If the amount cannot be formed by any combination of the coins, return -1. You may use an unlimited number of each coin.
•	Each coin denomination may be used any number of times (unlimited supply).
•	Return the minimum number of coins that sum to exactly amount, or -1 if it is impossible.
